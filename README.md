# 图书借阅管理系统

这是一个纯本地图书借阅管理软件，适合公司、单位或小型资料室在单台电脑上管理图书入库、库存、读者、借书、还书和逾期处理。

当前默认运行方式是本地 Web 管理界面：程序只监听 `127.0.0.1`，浏览器打开后使用，数据仍然保存在本机 SQLite 数据库中。

## 虚拟环境

请使用项目内虚拟环境运行，避免不同 Python 版本造成兼容问题：

```bash
/usr/bin/python3 -m venv .venv
source .venv/bin/activate
```

当前项目已经创建好 `.venv`。进入虚拟环境后可确认 Python 路径：

```bash
python -c "import sys; print(sys.executable)"
```

## 运行方式

进入虚拟环境后启动：

```bash
source .venv/bin/activate
python run.py
```

启动时终端会输出类似：

```text
[图书管理系统] 准备启动本地 Web 管理界面
[图书管理系统] 服务已启动：http://127.0.0.1:8765/
[图书管理系统] 数据文件：/Users/wwg/Documents/图书管理系统/data/library.db
```

程序会自动尝试打开浏览器。如果没有自动打开，请复制终端中的 `http://127.0.0.1:端口/` 地址到浏览器访问。

停止程序：回到终端按 `Ctrl+C`。

应用首次启动会自动创建 SQLite 数据库：

```text
data/library.db
```

项目不依赖第三方 Python 包。

## 功能范围

- 首页：今日借出、今日归还、逾期未还、零库存统计，并可对逾期记录执行续借或丢失报损。
- 图书入库：创建入库批次，输入条码后识别新书或老书，维护入库流水，确认后统一写入库存。
- 图书库存/调整：按关键词和书架查询库存，修改图书信息或库存数量时必须选择预设原因，并写入调整日志。
- 读者管理：登记姓名、手机号、部门和联系方式，查看当前在借与历史借阅。
- 读者借书：先查询并选择读者，再连续输入图书条码，确认后批量借出。
- 读者还书：先查询并选择读者，再录入归还条码，确认后恢复原书架库存。
- 系统设置：维护书架、库存调整原因、续借原因、丢失报损原因，以及默认借阅/续借天数。
- CSV 导出：库存导出可被 Excel 打开，条码、书号、ISBN 等纯数字字段会按文本保护。

## 数据说明

书号、ISBN、条码、手机号等字段在数据库中均使用 `TEXT` 类型保存，避免前导零丢失或长数字被错误转换。

## 测试

```bash
source .venv/bin/activate
python -m unittest discover -s tests
```

测试覆盖新书/老书入库、入库流水修改、库存调整日志、借书还书、逾期续借/报损和数字文本导出。
